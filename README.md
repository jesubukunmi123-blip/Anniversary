# Anniversary Bot 🎉

A Telegram bot that helps you track anniversaries, birthdays, and special dates with reminders.

## Features
- 📌 Save special dates
- ⏰ Upcoming date reminders
- 📋 View all saved dates
- 🗑️ Delete dates
- 🎯 Track important days

## Commands
- `/start` - Main menu
- `/add` - Add a special date
- `/list` - View all dates
- `/upcoming` - See upcoming dates
- `/delete` - Delete a date
- `/help` - Help menu

## Deployment
Deployed on Railway with GitHub integration.

## Tech Stack
- Python 3.11+
- pyTelegramBotAPI
- Railway
